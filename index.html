In OBS, add a Browser Source and paste this URL.

  1. Set the source to 750 wide × 630 high. Resize it in your scene.
  2. Keep this editor tab and the local server running. They send your controller inputs to OBS.
  3. Turn off “Shutdown source when not visible” and enable a 60 FPS custom frame rate if desired.
  4. Press your controller buttons and check the preview. Turn demo off before streaming.

This URL works in OBS on this computer. Chrome or Edge is recommended for the editor. Keep the editor in a visible window; some browsers pause controller polling in hidden tabs.
